# Глоссарий

Термины проекта с одним закреплённым значением. В скобках — английское название в
интерфейсе или имя в коде. Правила ведения — в `CLAUDE.md`, раздел «Документация».

## Граф

- **Нод** (node) — элемент графа: ссылка на тип нода, имя экземпляра, позиция на холсте и
  значения входов, заданные вручную.
- **Тип нода** (node type, `NodeTypeDef`) — описание операции: название, категория, порты
  и правило вычисления выходов по входам. Бывает встроенным и составным.
- **Экземпляр** (instance) — нод как представитель своего типа в конкретном графе.
  У составного нода определение одно, а экземпляров много; правка определения
  пересчитывает все экземпляры. Имя экземпляра — имя нода в графе, по умолчанию равно
  названию типа.
- **Составной нод** (composite node, `CompositeDef`) — тип нода, заданный внутренним
  графом; получается сворачиванием группы нодов. Его порты задают ноды «Input» и «Output»
  внутреннего графа. Определение хранится в библиотеке, экземпляры — в workflow.
- **Порт** (port, `PortDef`) — вход или выход нода с именем и типом (число, текст,
  логическое, массив, объект, любое). Значение порта — JSON-значение.
- **Связь** (link, `Edge`) — направленное соединение выходного порта одного нода с входным
  портом другого; допустима только при совместимых типах портов.
- **Workflow** (`Workflow`) — граф из нодов и связей без циклов, с идентификатором и
  именем; единица сохранения, выгрузки, загрузки и открытия во вкладке.
- **Библиотека составных нодов** (library) — все определения составных нодов хранилища;
  общая для всех workflow, показывается в палитре; целям вычисления передаётся отдельно
  от графов (сообщение `library`).

## Редактор

- **Вкладка** (tab) — открытый в редакторе workflow со своей позицией и масштабом холста
  и историей отмены. Для цели вычисления вкладка — документ (`doc`).
- **Холст** (canvas) — рабочая область с нодами и связями; занимает весь экран, остальные
  окна плавают поверх него.
- **Палитра** (Palette) — полоса с типами нодов по категориям внизу холста; открывается
  Пробелом, нод добавляется перетаскиванием или щелчком.
- **Окно свойств** (Properties, property grid) — плавающее окно выделенного нода: порты,
  их значения и состояние. Значения портов правятся только здесь; связи создаются
  перетаскиванием строки порта на другой нод.
- **Рабочая папка** (working folder) — папка на диске, выбранная пользователем; в неё
  автоматически сохраняются workflow и библиотека. Без папки — хранилище браузера (OPFS).

## Вычисление

- **Engine** (`@dagflow/engine`) — модель графа и реактивный вычислитель; один пакет для
  браузера, Node, Bun и Deno, без API среды (sans-IO).
- **Цель вычисления** (engine target) — где считается workflow: Local (то же окно),
  Worker (фоновый поток браузера), Server (сервер выполнения по адресу). Выбирается в
  разделе «Engine» левой панели, хранится в браузере, не в workflow.
- **Хост протокола** (host, `@dagflow/protocol`) — сторона цели: держит в памяти копии
  открытых вкладок, пересчитывает и отправляет состояния нодов. Один и тот же код в окне,
  в Worker и на сервере.
- **Клиент протокола** (client, `@dagflow/protocol`) — сторона редактора: отправляет хосту
  библиотеку и графы открытых вкладок, принимает состояния и единственный пишет их в стор.
- **Адаптер среды** (adapter) — тонкий слой между хостом или клиентом и вводом-выводом
  конкретной среды: канал в памяти для Local, `postMessage` для Worker, WebSocket для
  Node, Bun и Deno. Планирует пересчёт хоста своим таймером.
