# Выбор цели подключения в интерфейсе (черновик, 2026-10-07)

## Что есть в коде

- Верхняя панель: `MenuButton` + `TabBar` (`src/ui/Workbench.tsx`).
- Левая панель (`SidebarWindow`): `FolderBanner`, `StorageIndicator`, `WorkflowList`,
  `ExportImport`.
- Настройка «где хранятся данные» сохраняется в IndexedDB через `idb-keyval`
  (`src/storage/location.ts`, ключ `dagflow:folder`). Цель engine хранить так же
  (ключ `dagflow:engine`), а не в `localStorage`, — одно место для настроек браузера.
- Worker в проекте уже есть: `opfs-write-worker.ts`, создаётся
  `new Worker(new URL(...), { type: 'module' })` — Vite собирает его сам. Тот же приём
  для engine worker.

## Раздел «Engine» в левой панели (под «Storage») — решение 2026-10-07, правка

Один плоский список целей, без вложенности. Строка = индикатор выбранной + адрес +
тип подключения. Локальные цели — такие же строки списка.

```
┌ Menu ──────────────────────────────────┐
│ Storage: Browser        [Choose folder]│
│                                        │
│ Engine                                 │
│  ●  This tab              Local        │  ← выбрана (цвет = статус)
│     This browser          Worker       │
│     localhost:8080        Server     × │
│     domain.com            Server     × │
│     192.168.1.20:9000     Server     × │
│  [server address           ][Connect]  │
│                                        │
│ Workflows …                            │
└────────────────────────────────────────┘
```

- Щелчок по строке — подключение к этой цели (для серверов — пробное, см. ниже).
- Две локальные строки есть всегда, удалить их нельзя. Серверов в списке — до 5
  последних использованных; «×» убирает сервер.
- Поле + «Connect» внизу добавляет новый сервер: после успешного подключения он
  появляется в списке и становится выбранным.
- Индикатор выбранной строки: зелёный — подключено; иначе цвет статуса
  (подключение / offline / другая версия).
- Цель одна на весь редактор (все вкладки). По умолчанию — «This tab».
- Пользователь пишет короткий адрес: `localhost:8080`, `domain.com`,
  `domain.com/dagflow`. Схему в интерфейсе не видно — её подбирает подключатор.

## Подбор схемы (подключатор)

- Транспорт всегда WebSocket; варианты — только `wss://` (TLS) и `ws://`.
  `http://`/`https://`, если пользователь их ввёл, понимаются как `ws://`/`wss://`.
- Порядок попыток:
  - локальный адрес (`localhost`, `*.localhost`, `127.0.0.1`, `[::1]`): `ws` → `wss`;
  - любой другой: `wss` → `ws`;
  - страница открыта по `https://` и адрес не локальный: только `wss` (браузер
    запрещает `ws` — mixed content), ошибка объясняет это.
- Порт — ровно тот, что ввёл пользователь; свой порт подключатор не подставляет.
  Нет порта в адресе — URL без порта (браузер использует стандартный порт схемы:
  443 / 80). Неверный порт → понятная ошибка подключения.
- Путь (`domain.com/dagflow`) передаётся как есть — для сервера за обратным прокси.
  Сервер принимает WebSocket на любом пути.
- Успех попытки — только получение `welcome` (это именно наш engine), а не просто
  открытый сокет. Таймаут попытки — 3 с.
- Найденная схема запоминается у адреса в списке недавних; при переподключении
  сначала она, при неудаче — подбор заново.
- Незашифрованное подключение к не-локальному адресу: подбор разрешён, но в статусе
  видно «not encrypted» — чтобы понижение до `ws` не было незаметным.
- Хранится в IndexedDB (`dagflow:engine`): `{ target, recent: [{ address, scheme? }] }`.

## Переключение: пробное подключение

- Ручная смена цели **сначала пробует** новую цель и переключается только после
  `welcome`. Пока идёт попытка — «Connecting…» у кнопки, текущий engine работает.
- Неудача → ошибка у поля, прежняя цель остаётся:
  - «Could not connect to ws://localhost:8081. Check that the server is running.»
  - «The server runs a different engine version (0.3.0, editor 0.2.0).»
- Успех → старое соединение закрывается, все вкладки открываются на новом хосте,
  цель сохраняется.
- При **старте** и при **обрыве** — другое поведение (05-errors-reconnect.md):
  сохранённая цель, offline + повторные попытки + «Use local engine».

## Индикатор в верхней панели

Справа в `topbar`, после вкладок:

```
                                                   ● Server · localhost:8080
                                  ◌ Offline — retrying in 4 s   [Retry now]
```

- Щелчок открывает левую панель (раздел «Engine»).

## Решено

- По умолчанию — «In this tab».
- Индикатор в верхней панели виден всегда («● Local» / «● Server · localhost:8080» /
  «◌ Offline — retrying in 4 s [Retry now]»).
- Недавние серверы — список из 5, не выпадающий; активный помечен точкой.
- Параметра в адресе страницы нет.
