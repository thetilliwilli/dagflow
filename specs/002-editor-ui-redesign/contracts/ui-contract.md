# Contract: интерфейс редактора

Поведение и разметка, на которые опираются компонентные и e2e-тесты. Тексты —
только в `src/ui/messages.ts`.

## Рабочая область (FR-001, FR-004, FR-006a)

| Элемент | Разметка | Поведение |
|---|---|---|
| Кнопка меню | `button[aria-label="Меню"]`, левый верхний угол, `aria-expanded`, `data-attention="true"` и точка `.menu-button__dot`, пока есть сообщение о хранилище | показать/скрыть левую панель |
| Полоса вкладок | `role="tablist"` справа от кнопки меню | как в фиче 001 |
| Холст | занимает всю оставшуюся область | мини-карта, кнопки масштаба, панель инструментов (отменить, повторить, свернуть) — поверх холста |
| Сообщения о хранилище | `role="region" aria-label="Хранилище"` вверху левой панели | тексты и кнопки как в фиче 001; этап подсказки помнится в сторе интерфейса |

## Плавающие окна (FR-002, FR-003)

Общая разметка: `section.floating[role="dialog"][aria-modal="false"][aria-label=…]`,
заголовок `.floating__header` (за него перетаскивают), кнопка
`button[aria-label="Закрыть"]`.

| Окно | `aria-label` | Открытие | Закрытие | Положение по умолчанию |
|---|---|---|---|---|
| Левая панель | «Workflow и хранилище» | кнопка меню | кнопка меню, «Закрыть», Escape | у левого края под кнопкой меню |
| Палитра | «Палитра» | Пробел вне полей ввода | Пробел, «Закрыть», Escape | горизонтальная полоса внизу по центру, между кнопками масштаба и мини-картой |
| Окно свойств | «Свойства» | выделен ровно 1 нод | снятие выделения, Escape, «Закрыть» (снимает выделение) | у правого края под вкладками |
| Временное окно | «Свойства: &lt;имя нода&gt;» + `data-peek-node=<id>` | курсор над нодом при связывании | курсор ушёл с нода и окна, конец связывания | рядом с нодом |
| Окно связей | «Связи: &lt;A&gt; → &lt;B&gt;» | щелчок по линии или подписи | «Закрыть», Escape, щелчок по пустому холсту, нет связей | рядом с точкой щелчка |

- Окно остаётся в пределах окна редактора и после изменения его размера.
- Щелчок по окну или открытие поднимает его над остальными.
- Слой окон не перехватывает указатель вне окон: холст работает (FR-002).
- **Escape** — по приоритету: отменить связывание → закрыть верхнее окно.
  В поле ввода Escape отменяет ввод и окно не закрывает.

## Палитра (FR-005, FR-006)

- Вкладки: `role="tablist" aria-label="Категории"`, вкладка — `role="tab"` с
  названием категории; порядок — `categories` движка, затем «Мои составные ноды»;
  «Интерфейс составного нода» — только во вкладке составного нода.
- Элемент: `.palette__item` с `.palette__item-title`, описанием и строкой портов
  (как в фиче 001). Перетаскивание на холст — нод в точке броска; одиночный
  щелчок — нод в центре видимой области. Палитра остаётся открытой.
- Пробел в `input`, `textarea`, `select`, `[contenteditable]` и во время
  связывания палитру не переключает. Пробел не панорамирует холст.

## Карточка нода (FR-007, FR-007a, FR-008, FR-011)

```text
div.flow-node.status-<status>[.is-selected][.is-link-target]
├── span.flow-node__type     (тип, серый, 1 строка, title = полное)
├── span.flow-node__name     (имя, по центру, ≤ 3 строки, title = полное)
├── NodeStatusBadge          (значок состояния)
└── div.flow-node__problem   (только waiting/error/blocked, 1 строка, title = полное)
```

- Прямоугольник без скругления; ширина 20–40 символов имени; высота одинакова.
- Рамка — чёрная, как на скриншотах; у выделенного нода — синяя (`--selected`).
  Состояние рамку не красит: его показывают цветной значок и строка проблемы,
  поэтому выделение и состояние не путаются (US2, сценарий 7).
- Двойной щелчок по имени — поле ввода; Enter или потеря фокуса — `renameNode`;
  Escape — отмена. Отказ показывается под полем.
- На карточке нет видимых портов и значений.

## Окно свойств (FR-012 – FR-017)

```text
section.floating[aria-label="Свойства"]
├── заголовок: имя (переименование двойным щелчком) + тип
├── состояние и текст проблемы (FR-016)
├── действия: «Открыть», «Развернуть» (составной), редактор портов (Вход/Выход)
├── section[aria-label="Входы"]  > ul > li.prop-row[data-side="in"][data-port=<имя>]
└── section[aria-label="Выходы"] > ul > li.prop-row[data-side="out"][data-port=<имя>]
```

Строка: `[маркер] [тип] [имя] [значение]`

| Часть | Разметка | Правила |
|---|---|---|
| Маркер | `button.prop-marker[aria-label="Связать «<имя>»"][aria-pressed]`, `.is-linked` | квадрат с рамкой; зелёный, если есть хотя бы одна связь порта; серый — нет |
| Тип | `span.prop-type[title=<полное название>]` | `num`, `str`, `bool`, `arr`, `obj`, `any` |
| Имя | `span.prop-name` | имя порта |
| Значение | вход без связи — `ValueEditor` (`aria-label=<имя>`); вход со связью — `ValueView` + «← &lt;нод&gt;.&lt;выход&gt;»; выход — `ValueView` | обновляется в реальном времени |

Пустая панель — текст «Нет входов» / «Нет выходов».

## Связывание (FR-018 – FR-022)

- **Перетаскивание**: нажать на маркер или имя строки и сдвинуть больше 4 px →
  за курсором метка `.link-ghost` «&lt;имя&gt; (&lt;тип&gt;)»; холст не двигается.
- **Режим привязки**: щелчок по маркеру → `aria-pressed="true"`, строка
  `.is-linking`, подсказка «Выберите нод и параметр для связи».
- Над нодом B (или по щелчку на нём в режиме привязки) — временное окно B; его
  строки — `li.prop-row` с `.is-disabled` и `aria-disabled="true"` для
  недоступных (`title` = текст отказа). Набор и порядок строк такие же, как у
  обычного окна свойств B.
- Бросок / щелчок по доступной строке → `connect`, связывание завершается, выделен
  остаётся нод A. По недоступной → уведомление с текстом отказа; перетаскивание
  завершается, режим привязки — нет.
- Отмена: бросок вне строк, Escape; в режиме привязки также щелчок по пустому
  холсту или повторный щелчок по маркеру.
- Пока идёт связывание, ноды нельзя двигать и выделять.

## Линии связей (FR-023 – FR-025)

- Одно ребро на пучок: `.react-flow__edge` с id `bundle:<A>-><B>` (тест-id React Flow —
  `rf__edge-bundle:<A>-><B>`), прямая линия, стрелка у B, концы на рамках карточек.
- Подпись `.bundle-label`: строки «выход→вход», не больше 5, затем «ещё N»;
  не отображается при масштабе < 50%.
- Щелчок по линии или подписи — окно связей: `li` на связь с текстом
  «выход→вход» и `button[aria-label="Удалить связь «выход→вход»"]` (крестик).
- Выделенная линия + Delete удаляет все связи пучка одним шагом (как удаление
  связей в фиче 001). Линия после щелчка в фокусе, и Escape (поведение React Flow)
  снимает с неё выделение.
