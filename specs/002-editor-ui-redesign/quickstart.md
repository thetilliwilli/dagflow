# Quickstart: проверка фичи 002-editor-ui-redesign

Запуск и команды — как в [quickstart фичи 001](../001-dag-workflow-editor/quickstart.md#команды).
Разметка и поведение — в [contracts/ui-contract.md](./contracts/ui-contract.md).
Автоматическая версия сценариев — `tests/e2e/ui-us1…us5-*.spec.ts`.

```bash
npm run dev        # http://localhost:5173
npm test           # unit + component
npm run test:e2e   # e2e (Chromium), включая сценарии 001 на новых хелперах
npm run test:perf  # SC-002/SC-003 фичи 001 и SC-005 этой фичи
```

## US1 — холст и плавающие окна

1. Открыть редактор. **Ожидается**: вкладки и холст на всё окно, слева вверху
   кнопка ☰ (с точкой, пока есть сообщение о хранилище), боковой панели нет.
2. Нажать ☰. **Ожидается**: плавающая панель поверх холста; вверху — сообщение о
   хранилище («Выберите рабочую папку…»), ниже — хранилище и список workflow; холст
   за панелью можно двигать колёсиком и мышью. «Позже» → «Понятно» — сообщение ушло,
   точка на ☰ погасла. Escape — панель скрылась.
3. Щёлкнуть по холсту, нажать Пробел. **Ожидается**: палитра — горизонтальная
   полоса внизу по центру, между кнопками масштаба и мини-картой, с вкладками
   категорий. Открыть «Арифметика», щёлкнуть «Сложить» — нод в центре холста над
   палитрой, палитра открыта. Перетащить «Число» на холст — нод в точке броска.
4. Перетащить палитру за заголовок к краю экрана и дальше. **Ожидается**: окно
   упирается в край и не уходит за пределы.
5. Начать переименование нода (двойной щелчок по имени), нажать Пробел.
   **Ожидается**: в имени появился пробел, палитра не переключилась.

## US2 — вид нода и выделение

1. Добавить «Сложить». **Ожидается**: прямоугольник без скруглений, слева вверху
   серым «Сложить», по центру «Сложить».
2. Двойной щелчок по имени, ввести «Итого», Enter. **Ожидается**: по центру
   «Итого», тип прежний. Ctrl+Z — снова «Сложить».
3. Ввести имя из 120 символов. **Ожидается**: отказ «…длиннее 100 символов…».
   Ввести имя 90 символов — ширина нода не больше 40 символов, имя в 3 строки с
   многоточием, полное — во всплывающей подсказке.
4. Выделить нод — рамка синяя; снять выделение — чёрная.
5. Оставить вход «a» пустым. **Ожидается**: значок «ожидает входов» и строка о
   незаполненном входе «a» на карточке (текст — как в фиче 001).
6. Перезагрузить страницу (подождав ~1 с). **Ожидается**: имя «Итого» на месте.
7. Загрузить файл выгрузки, сделанный до фичи 002 (ноды без `name`).
   **Ожидается**: понятная ошибка, список workflow не изменился.

## US3 — окно свойств

1. Собрать «Число 2», «Число 3», «Сложить», связать (US4). Выделить «Сложить».
   **Ожидается**: справа окно «Свойства», панели «Входы» (`num a`, `num b`, обе с
   зелёным маркером и «← Число.value») и «Выходы» (`num result` = 5).
2. Выделить «Число 2», в окне изменить 2 → 10. Выделить «Сложить» — 13.
3. Сдвинуть холст. **Ожидается**: окно свойств стоит на месте.
4. Выделить два нода рамкой. **Ожидается**: окна свойств нет.
5. Свернуть два нода в составной; выделить экземпляр. **Ожидается**: в окне
   кнопки «Открыть» и «Развернуть»; внутри составного у нода «Вход» — редактор
   портов.

## US4 — связывание

1. Выделить «Число 2», потянуть строку `value` из окна свойств на «Сложить».
   **Ожидается**: за курсором метка; над «Сложить» — временное окно; строки
   «Выходы» и несовместимые входы серые, но на месте. Отпустить на `a` — связь
   есть, маркеры `value` и `a` зелёные.
2. Добавить «Текст», выделить его, щёлкнуть по маркеру `value`, щёлкнуть по
   «Сложить». **Ожидается**: строки `a`, `b` серые; щелчок по `b` — уведомление
   «Несовместимые типы: текст → число…», режим привязки продолжается. Escape —
   режим завершён.
3. В цепочке A → B потянуть выход B на A. **Ожидается**: входы A серые,
   подсказка «…образует цикл».
4. Перетащить вход «Сложить» `b` на выход «Число 3» — связь Число 3 → b.

## US5 — линии связей

1. Связать выход «Число» `value` со входами `a` и `b` «Сложить». **Ожидается**:
   одна прямая линия со стрелкой к «Сложить», подпись в 2 строки «value→a»,
   «value→b».
2. Подвинуть нод — линия прямая, подпись едет с ней.
3. Щёлкнуть по линии, нажать крестик у «value→b». **Ожидается**: подпись в 1
   строку, `b` в окне свойств снова с серым маркером. Ctrl+Z — связь вернулась.
4. Уменьшить холст до 40%. **Ожидается**: подписей нет, линии со стрелками есть;
   щелчок по линии открывает окно связей.

## Регрессия фичи 001

Пройти сценарии [quickstart 001](../001-dag-workflow-editor/quickstart.md#сценарии-проверки)
новым способом связывания: реактивность, отказы, хранение, вкладки, составные
ноды, отмена — без изменений поведения.

## Критерии успеха

| Критерий | Как проверить |
|---|---|
| SC-001 | e2e: размеры холста = окно минус полоса вкладок |
| SC-002 | ручная проверка новым пользователем, ≤ 15 с на связь |
| SC-003 | e2e US4: затенение до броска, строки не сдвигаются (координаты до/во время) |
| SC-004 | unit `bundleEdges` + e2e: число `.react-flow__edge` = число пар |
| SC-005 | `npm run test:perf`: окно свойств и временное окно < 100 мс на 100 нодах |
| SC-006 | e2e US5: удаление связи за 2 щелчка |
| SC-007 | unit: схема отклоняет ноды без имён; e2e выгрузка/загрузка с именами и отказ для старого файла |
| SC-008 | `npm run test:perf`: SC-002/SC-003 фичи 001 |
| SC-009 | компонентный тест маркеров |
