# Quickstart: проверка фичи 003-english-ui-unicode-names

Команды — как в [quickstart фичи 001](../001-dag-workflow-editor/quickstart.md#команды).
Формулировки — [contracts/ui-texts.md](./contracts/ui-texts.md).

## US1 — интерфейс на английском

1. Открыть редактор в чистом профиле. **Ожидается**: вкладка «New workflow», кнопки
   «Undo»/«Redo», заголовок вкладки браузера «DAG Flow».
2. Открыть ☰. **Ожидается**: «Workflows & storage», сообщение «Choose a working
   folder…», «Create workflow», «Export to file», «Import from file», ссылка «github».
3. Пробел. **Ожидается**: вкладки «Constants», «Math», …, «My composite nodes»;
   «Add» с описанием «a + b». Добавить «Add» — имя на карточке «Add», тип «Add».
4. Выделить нод. **Ожидается**: «Properties», «Inputs», «Outputs», «waiting for
   inputs», «Fill in input “a”.».
5. Ошибки: цикл, «Text» → вход «Add», деление на ноль, пустое имя, загрузка
   текстового файла. **Ожидается**: тексты из раздела «Отказы» и «Импорт» контракта.
6. Щёлкнуть по линии — «Links: A → B», крестик «Delete link “…”». Удалить workflow —
   «Delete workflow?».
7. Нигде в сценариях 1–6 нет кириллицы.

## US2 — имена без ограничений длины

1. Переименовать нод фразой из 300 символов. **Ожидается**: принято; карточка не шире
   предела, имя в 3 строки с многоточием, полное — в подсказке и окне свойств.
2. Назвать workflow строкой из 200 символов, составной нод — из 150, порт нода «Input»
   — из 80. **Ожидается**: всё принято; вкладка, список и палитра — с многоточием и
   подсказкой.
3. Пустое имя и одни пробелы — отказ.
4. Имена «Итого», «合計», «مجموع», «Résumé 📈» — выгрузить, загрузить, перезагрузить
   страницу. **Ожидается**: посимвольно те же.

## US3 — старая работа

1. Открыть рабочую папку, сохранённую до фичи 003. **Ожидается**: workflow
   открываются и вычисляются; нод «Сложить» сохраняет имя, тип в углу — «Add».

## Критерии успеха

| Критерий | Как проверить |
|---|---|
| SC-001 | e2e: обход окон и ошибок без кириллицы в документе |
| SC-002 | unit: названия и описания встроенных нодов и категорий совпадают с контрактом |
| SC-003 | проверок длины в коде нет; unit/e2e: пустое имя отклоняется |
| SC-004 | e2e: имена на разных языках после выгрузки, загрузки и перезагрузки |
| SC-005 | e2e: фикстура в формате 002 открывается и вычисляется |
| SC-006 | ручная проверка формулировок по контракту |
