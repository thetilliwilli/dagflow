# Data Model: Английский интерфейс и имена без ограничений длины

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md)

Модель фич 001 и 002 сохраняется. Меняются только правила имён (FR-007).

## Правила имён

| Поле | Было | Стало |
|---|---|---|
| `NodeInstance.name` (002) | после `trim` 1–100 символов | после `trim` не пустое |
| `Workflow.name` (001) | 1–100 символов | после `trim` не пустое |
| `CompositeDef.name` (001) | 1–100 символов; уникально в палитре | после `trim` не пустое; уникально в палитре (без изменений) |
| `PortDef.name` у нодов «Input»/«Output» (001) | 1–40 символов; уникально среди нодов «Input» (и среди «Output») | не пустое; уникальность без изменений |

- Имя хранится как введено (после обрезки пробелов по краям), на любом языке;
  длина не ограничена.
- Сгенерированные имена: имя нода по умолчанию — английское название типа; новый
  workflow — «New workflow»; копия — «<name> (copy)»; копия из браузера при слиянии —
  «<name> (from browser)»; конфликт имён составных нодов при импорте — «<name> (2)»,
  «(3)»… (без изменений). Ни одно сгенерированное имя не обрезается.
- Имена, сохранённые раньше (в том числе русские имена по умолчанию из 002), не
  меняются.

## Формат файлов

Не меняется (`version: 1`). Схема только ослабляется: исчезают верхние пределы длины
имён — все файлы, корректные раньше, остаются корректными (FR-010).
