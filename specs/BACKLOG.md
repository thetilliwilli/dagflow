# Backlog: отложенные фичи

Фичи, о которых договорились, но которые ещё не начаты. Это соглашение проекта, а
не артефакт Spec Kit. Как пользоваться:

- Новая фича начинается на `master` командой `/speckit-specify` с текстом из
  поля «Описание для /speckit-specify».
- Начатая фича удаляется отсюда в том же коммите, где появляется её `spec.md`.
  Источником истины становится каталог `specs/NNN-…/`.
- Номер фичи здесь предварительный: его выдаёт `/speckit-specify` по порядку.

## 003 — английский интерфейс и имена на любом языке

- **Откуда**: вынесено из `002-editor-ui-redesign` при планировании 2026-10-05
  (spec.md 002, разделы Clarifications и Assumptions), чтобы не раздувать 002.
- **Когда начинать**: после слияния 002 в `master`. Фичи меняют одни и те же
  файлы (`messages.ts`, карточка нода, e2e-тесты).
- **Описание для /speckit-specify**: весь интерфейс редактора на английском:
  подписи, окна, состояния нодов, уведомления, сообщения об ошибках, названия и
  описания встроенных нодов и категорий палитры. Имена, которые задаёт
  пользователь (ноды, workflow, составные ноды, порты), могут быть на любом языке
  с полной поддержкой Unicode: они отображаются, сохраняются, выгружаются и
  загружаются без искажений; длина имён считается в символах, а не в байтах.
  Переключения языка нет. Артефакты Spec Kit и комментарии в коде остаются на
  русском.
- **Заметки к плану**:
  - около 40 тестовых файлов проверяют русские строки;
  - правило в `CLAUDE.md` «интерфейс на русском» нужно поменять;
  - Valibot `maxLength` считает кодовые единицы UTF-16 (эмодзи — два символа);
  - нужны системные шрифты с запасными вариантами и `dir="auto"` для имён,
    которые пишутся справа налево.
