# Quickstart: проверка фичи 001-dag-workflow-editor

Руководство по запуску и ручной/автоматической проверке. Детали моделей и форматов
описаны в [data-model.md](./data-model.md) и [contracts/](./contracts/).

## Требования

- Node.js 24 LTS, npm 11+
- Chromium-браузер (Chrome, Edge, Яндекс) для проверки рабочей папки; Firefox или
  Safari — для проверки запасного хранилища
- Для e2e: `npx playwright install chromium`

## Команды

```bash
npm install
npm run dev          # редактор на http://localhost:5173
npm test             # unit + component тесты (Vitest)
npm run test:e2e     # e2e (Playwright, Chromium)
npm run typecheck    # tsc для приложения и отдельно для движка (без DOM)
npm run build        # production-сборка в dist/
```

## Сценарии проверки

Каждый сценарий соответствует user story спеки. Автоматическая версия —
в `tests/e2e/`.

### US1 — граф и реактивность (P1)

1. Открыть редактор, создать workflow.
2. Добавить «Число» (2), «Число» (3), «Сложить», «Показать»; соединить
   2 → a, 3 → b, result → value.
3. **Ожидается**: «Показать» отображает `5` без нажатия каких-либо кнопок.
4. Изменить первое число на 10. **Ожидается**: `13` появляется сразу; у нода
   «Число 3» значение не пересчитывалось (тест E1 в unit-тестах движка).

### US2 — защита и ошибки (P2)

1. В цепочке A → B → C потянуть связь C → A. **Ожидается**: связь не создаётся,
   подсказка «…образует цикл».
2. Соединить выход «Текст» со входом «Сложить». **Ожидается**: отказ «…несовместимые
   типы: текст → число».
3. Собрать «Разделить» с b = 0 и «Показать» после него. **Ожидается**: на
   «Разделить» — ошибка «Деление на ноль…», «Показать» — «не вычислен: проблема выше по графу». Изменить b на 2 — ошибка исчезает сама.

### US3 — хранение и вкладки (P3)

1. Chromium: при первом запуске выбрать пустую папку. Создать два workflow и
   открыть оба во вкладках.
2. **Ожидается**: в папке появились `workspace.json`, `workflows/*.workflow.json`.
3. Перезагрузить страницу. **Ожидается**: если браузер требует подтверждения —
   экран «Восстановить доступ к папке» (одно нажатие, до него данные не
   загружаются); обе вкладки открыты, графы вычислены.
3a. Выбрать другую папку, где уже есть данные редактора. **Ожидается**: загружены
   данные этой папки, предложено добавить workflow, которых в ней нет; файлы
   папки не перезаписаны.
4. Выгрузить workflow в файл, загрузить его. **Ожидается**: новый workflow в
   списке, идентичный исходному.
5. Загрузить произвольный `.txt`. **Ожидается**: понятная ошибка, список не
   изменился.
6. Firefox: **ожидается** индикатор «Данные хранятся в браузере», автосохранение
   работает после перезагрузки.

### US4 — составные ноды (P4)

1. Собрать (a + b) × 2, выделить «Сложить» и «Умножить», «Свернуть в составной
   нод» → «Удвоенная сумма». **Ожидается**: значения графа не изменились, внутри
   созданы «Вход» (a, b) и «Выход» (result).
2. Добавить второй экземпляр из палитры с другими входами. **Ожидается**: оба
   считают верно.
3. Открыть нод (отдельная вкладка), заменить × 2 на × 3. **Ожидается**: оба
   экземпляра пересчитались во всех вкладках.
4. Попытаться поместить «Удвоенная сумма» внутрь самой себя. **Ожидается**: отказ.
5. Выгрузить workflow, удалить нод из палитры, загрузить файл. **Ожидается**:
   нод восстановлен из файла.

### US5 — удобство (P5)

1. Граф из 20+ нодов: перемещение и масштаб холста, выделение рамкой, удаление
   группы, Ctrl+Z / Ctrl+Shift+Z. **Ожидается**: ноды, связи и значения
   возвращаются.

## Проверка критериев успеха

| SC | Как проверить |
|---|---|
| SC-002 | e2e-тест с графом из 100 нодов замеряет внутри страницы (`performance.mark`/`measure`) время от действия до отрисовки (< 100 мс) |
| SC-003 | unit-бенчмарк движка: цепочка из 100 нодов, `setValue` + `flush` < 200 мс (с запасом — проверяем < 20 мс без UI) и e2e-замер с UI |
| SC-004 | unit-тесты `canConnect` на циклы и все пары типов |
| SC-005 | unit-тест: экспорт → импорт → глубокое равенство графа и значений |
| SC-008 | e2e: изменение → ожидание 1 с → перезагрузка → изменение на месте |
| SC-001, SC-007 | ручная проверка с новым пользователем |
